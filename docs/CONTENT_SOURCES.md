# Content Sources

Content provenance rules: we **link, don't copy** copyrighted material. Four
source classes: ORIGINAL / AI_GENERATED / OPEN_LICENSED / USER_IMPORTED.

| Content group | Basis | License | Status | Material |
|---|---|---|---|---|
| Lesson curriculum (`src/lib/content/lessons/*`) | Original, written for this project | CC0 (original) | Original | Rewritten explanations, examples |
| Practice sets (Reading/Listening) | Original passages + questions | CC0 (original) | Original | No official/Cambridge questions |
| Listening audio (`public/audio/*`) | Original scripts → Piper TTS | CC0 (original) | Original | Generated audio only |
| Writing prompts | Original IELTS-style | CC0 (original) | Original | Structured chart/table data |
| Speaking topics | Original IELTS-style | CC0 (original) | Original | Not "current real" questions |
| Grammar lessons/exercises | Original | CC0 (original) | Original | Error types + explanations |
| Official-format notes (`knowledge/official-notes.json`) | Rewritten summaries | CC0 (original) | Original summary | Not copied pages; links only |
| Resource Center official links | IELTS.org / British Council / IDP | n/a | Official | Link only |
| Open-source projects (ists, echo-type, …) | Referenced repositories | MIT/GPL (code) | Reference | Ideas/architecture only |
| Baicizhan vocabulary | Community API adapter | Proprietary (not bundled) | External | Fetched at runtime |

Open-source code licenses (e.g. MIT) do **not** imply their embedded IELTS
questions are redistributable. Where provenance is uncertain we use
architecture/ideas only and write original content.

`lastVerified` dates are updated only after actual verification.
