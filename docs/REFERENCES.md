# References

## Official IELTS sources (canonical)

- IELTS official website — https://ielts.org (test format, One Skill Retake,
  Writing on Paper; jointly owned by British Council, IDP IELTS, Cambridge
  University Press & Assessment).
- British Council "Take IELTS" — https://takeielts.britishcouncil.org
- IDP IELTS — https://ielts.idp.com

Official sources are treated as canonical for exam structure, question types,
timing, scoring, band descriptors and Academic vs General differences. Where
official guidance notes that raw-score thresholds may vary slightly between test
versions, this project represents conversion tables as honest approximations.
